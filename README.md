# Шлем спасает жизнь: Цифровой гид по пассивной безопасности СИМ

Интерактивный веб-ресурс, посвященный профилактике травматизма и популяризации средств пассивной безопасности водителей средств индивидуальной мобильности (СИМ) и велосипедистов.

## О проекте
Проект разработан в рамках исследования по снижению дорожно-транспортного травматизма. В основе ресурса — сочетание наглядного образовательного контента с практическими интерактивными инструментами:
- **6 правил безопасного вождения СИМ**: карточки с нормами ПДД РФ (пп. 24.5, 24.6, 24.8) и ГОСТ Р 59882-2021.
- **Математический симулятор торможения**: физический расчет остановочного пути и энергии удара при различных скоростях и типах дорожного покрытия.
- **Инспектор устройства шлема**: интерактивная SVG-схема слоев защиты шлема стандарта EN 1078.
- **Калькулятор размера шлема**: подбор экипировки по обхвату головы с рекомендациями по посадке «2-V-1».
- **Чек-лист безопасности**: интерактивная экспресс-проверка готовности райдера к выезду.
- **Ситуационный квиз**: тестирование на знание поведения в реальных дорожных условиях.

## Стек технологий
- **HTML5**: семантическая разметка, доступность.
- **CSS3**: CSS Variables, Grid, Flexbox, Glow/Box-shadow эффекты, адаптивность для мобильных устройств.
- **JavaScript (ES6+)**: чистый Vanilla JS без сторонних библиотек.
- **Типографика**: шрифт Inter (кегль от 14px и выше).
